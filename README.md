Entry for the [Pigeon Pitch, One Line](https://make.fun/bounty/u-donrulezz-pigeon-pitch-one-line-af06c6cf) bounty on make.fun: a program that writes the one-line elevator pitch a city pigeon gives investors for its startup.

## The pitch

> Investors, I'm raising a seed round — literally seeds — for CooDrop: my 10,000 pigeons deliver your lunch crumbs before you drop them. No drivers, no apps, just coo.

## Run

```sh
python3 main.py
```

Writes the pitch to `/output/entry.txt` (creating the directory if needed), prints it, and self-checks that it is UTF-8, a single line, and 1–200 characters. Pure Python standard library only — no third-party packages, no network, deterministic output.
